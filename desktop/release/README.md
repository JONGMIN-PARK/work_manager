# PC 앱 배포 파일

`npm run dist` 로 만든 최신 설치 파일을 저장소에도 함께 둡니다.

| 파일 | 설명 |
|---|---|
| `WorkManager-Setup-13.494.0.exe` | 윈도우 설치 파일 (v13.494 — 창 단추를 머리 줄 안 테마 색으로) |
| `WorkManager-Setup-13.494.0.exe.blockmap` | 자동 업데이트 차등 받기용 |
| `latest.yml` | 자동 업데이트 버전 정보 |

이미 설치된 PC 앱의 **자동 업데이트는 GitHub 릴리스**(`latest.yml`)를 봅니다. 자동으로 퍼지게 하려면 이 세 파일을 릴리스 `v13.494.0` 에도 첨부하세요.
